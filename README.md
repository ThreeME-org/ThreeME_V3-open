# ThreeME_V3-open

All information on running the model can be found in the 'doc' folder.

'Manual for running the ThreeME model for results in the wp.docx' gives a step-by-step instruction on how to run the model to obtain the results from the paper.
'ThreeME_User Guide.docx' gives a general description of the model.
'ThreeME_V3_Full_description.pdf' is a manual that provides all formula's in the base model. Changes to the model - for the purpose of the article - are not included in this manual.


Notice that the code may differ from the description made in the User Guide.

You can also get more information on the ThreeME homepage: https://www.threeme.org/

Note about this version:

This branch allows for the replication of the simulation results published in:

Jacquetin, F. & Callonnec, G. (2024). Macroeconomic Impact of Climate Damage in France. Economie et Statistique / Economics and Statistics, 543, 39–64. 
doi:10.24187/ecostat.2024.543.2118

and provided in the 'doc' folder: 'Jacquetin-Callonnec2024_EcoStat-543-EN.pdf'

Figures from the paper can be reproduced using the template "Results_France.xlsx" (located in the folder "results"). 
The results are produced in the folder "results".
